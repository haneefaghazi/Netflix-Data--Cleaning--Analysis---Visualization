# 📊 Netflix Data: Cleaning, Analysis, and Visualization

This project focuses on the analysis and visualization of Netflix’s movie and TV show data. By cleaning raw data, handling missing values, and applying analytical techniques, the goal is to uncover key insights into Netflix's content, such as trends in genres, release years, and viewer ratings. Through data visualization, the project also highlights patterns in viewing habits, content diversity, and global reach.

## 🧰 Tools & Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- SQL (for data storage, if applicable)

## 🔄 Workflow

### 1. Data Cleaning
- Removed duplicates and handled missing values
- Corrected inconsistencies in data formats
- Standardized column names for better readability

### 2. Data Analysis
- Analyzed trends in genres, release years, and average ratings
- Investigated the distribution of content across regions
- Explored correlations between movie ratings and release years

### 3. Data Visualization
- Created visualizations such as bar charts, pie charts, and histograms
- Visualized the distribution of genres, content types, and ratings over time
- Produced heatmaps and scatter plots to show relationships between variables

## 📈 Results

- Identified top genres and most frequent release years
- Analyzed the distribution of Netflix content across different regions
- Visualized changes in content diversity and rating trends over the years

## 🧠 Insights

- Action and drama are the most common genres on Netflix.
- The content release pattern shows a spike in newer original productions.
- Ratings are generally higher for newer content but vary by genre.
